# Smart Energy Consumption Prediction

This project predicts electricity consumption using Random Forest and detects anomalous consumption patterns using Isolation Forest.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
